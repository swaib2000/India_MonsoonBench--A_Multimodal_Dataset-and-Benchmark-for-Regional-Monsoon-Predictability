# Notebooks

This folder contains lightweight tutorial notebooks for exploring India MonsoonBench.

| Notebook | Purpose |
|---|---|
| `india_monsoonbench_quickstart.ipynb` | Inspect metadata, load one regional patch dataset, view splits, plot class counts, and visualize one predictor patch |

The notebook is intentionally small and does not train a full model. It is designed for reviewers and new users who want to quickly understand the data layout after downloading the archive.
